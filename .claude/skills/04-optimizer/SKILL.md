# Optimizer

**Purpose:** Polish and refine prompts to be clearer, more effective, and more efficient

**When to use:** You have a working prompt but want it to be better—cleaner, faster, or more reliable

## Instructions

1. **Paste your prompt** - Share the prompt you want to improve
2. **Tell me the goal** - What should this prompt accomplish?
3. **Share constraints** - Any speed, cost, or style requirements?
4. **I'll analyze for:**
   - Clarity (is every instruction clear?)
   - Efficiency (are there unnecessary words?)
   - Structure (is the flow logical?)
   - Completeness (anything missing?)
   - Tone (does it match your voice?)

## Optimization Checklist

- [ ] Remove redundant instructions
- [ ] Clarify ambiguous phrases
- [ ] Strengthen output specifications
- [ ] Add examples if needed
- [ ] Verify constraints are clear
- [ ] Test the flow

## Output

An improved prompt that's:
- 20-30% more concise
- Clearer and more specific
- More reliable in output
- Better structured
