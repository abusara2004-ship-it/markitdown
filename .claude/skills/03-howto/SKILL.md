# HowTo

**Purpose:** Map out the steps you don't know yet—turn vague processes into step-by-step guides

**When to use:** When you need a tutorial, guide, or walkthrough of an unfamiliar process

## Instructions

1. **Share your goal** - What do you want to accomplish?
2. **Tell me your starting point** - What's your current knowledge/state?
3. **Identify gaps** - What steps are unclear or missing?
4. **Build the map** - I'll create a step-by-step breakdown:
   - Prerequisites (what you need first)
   - Main steps (in order, clear and specific)
   - Common pitfalls (what to avoid)
   - Tips & tricks
   - Verification (how to know you did it right)

## Output Format

```
## [Process Name]

### Prerequisites
- [ ] Item 1
- [ ] Item 2

### Steps
1. **Step 1** - Description with reasoning
2. **Step 2** - Description with reasoning
...

### Common Mistakes
- Mistake 1: Why it happens, how to avoid

### Pro Tips
- Tip 1
- Tip 2

### How to Know You Did It Right
- Check 1
- Check 2
```
