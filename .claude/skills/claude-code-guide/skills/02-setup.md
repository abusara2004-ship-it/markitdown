# Claude Code Setup - 5 Minutes

Complete Claude Code setup and configuration in 5 minutes.

## Quick Start Checklist

- [ ] Download Claude Code (Pro $20 or free tier)
- [ ] Install in your IDE or use web version
- [ ] Verify basic permissions
- [ ] Test with a sample project
- [ ] Configure notifications (optional)

## Installation Steps

### 1. Get Claude Code
- Visit: `claude.com/download`
- Download Pro Code ($20) - Recommended
- Or use free tier access

### 2. Initial Configuration
**Time: 2 minutes**
- Open settings
- Configure basic preferences
- Connect GitHub (optional)

### 3. Permissions Setup
**Time: 1 minute**
- Allow file access
- Configure terminal access (if needed)
- Review security settings

### 4. Model Selection
**Time: 1 minute**
- Select **Opus 5, High** (recommended)
- Alternative: Use default model
- Verify API access

### 5. Features Enable (Optional)
**Time: 1 minute**
- Enable Notify for notifications
- Connect Superbase for data storage
- Configure GitHub integration

## Configuration Options

### Basic Settings
```
- Theme: Light/Dark
- Font Size: Default
- Line Numbers: On
- Auto-save: Enabled
```

### Advanced Settings
```
- Bypass Permissions: Configure cautiously
- API Rate Limits: Set appropriately
- Cache Settings: Enable for performance
- Debug Mode: Off by default
```

## Important Notes

⚠️ **Security First**
- Review all permission requests
- Never bypass permissions for untrusted code
- Use secure connections for sensitive data

📝 **Best Practices**
- Start with a sample project
- Test basic workflows first
- Review documentation before advanced features

💡 **Tips**
- Use keyboard shortcuts for efficiency
- Configure notifications for updates
- Enable auto-save to prevent data loss

## Verify Installation

Test with a simple command:
```bash
claude --version
```

Expected output:
```
Claude Code v[version]
```

## Troubleshooting

**Issue:** Can't find settings
- Solution: Use `/config` command

**Issue:** Permissions denied
- Solution: Review privacy settings in preferences

**Issue:** Model not loading
- Solution: Verify API key configuration
