# Claude Code Guide - Skills Package

Complete, production-ready Claude Code learning guide with 4 progressive skills sections.

## 📚 Skills Included

### Skill 1: Is It For You? (`01-is-it-for-you.md`)
- **Duration:** 5 minutes
- **Difficulty:** Beginner
- **What you'll learn:** Whether Claude Code fits your needs, required resources, getting started checklist

### Skill 2: Setup (`02-setup.md`)
- **Duration:** 5 minutes  
- **Difficulty:** Beginner
- **What you'll learn:** Installation, configuration, permissions setup, model selection

### Skill 3: The One Prompt You Need (`03-the-prompt.md`)
- **Duration:** 30 minutes
- **Difficulty:** Intermediate
- **What you'll learn:** Prompt engineering, real-world examples, advanced techniques, GitHub integration

### Skill 4: Unlearn (`04-unlearn.md`)
- **Duration:** 1-2 weeks practice
- **Difficulty:** Advanced
- **What you'll learn:** Mental model shifts, breaking bad habits, productive patterns, mastery
