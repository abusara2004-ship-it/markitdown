# WriteaSkill

**Purpose:** Package your prompt as a reusable skill—bottleneck it into something you'll actually use

**When to use:** You have a great prompt that you'll use repeatedly, and you want it as a proper skill

## Instructions

1. **Bring your prompt** - The one you've refined and perfected
2. **Define the skill:**
   - What's the clear, one-sentence purpose?
   - What does it take as input?
   - What's the expected output?
   - When should someone use it vs. other skills?
3. **Create the skill file** - I'll structure it as a proper .md skill
4. **Add to your toolkit** - It becomes `/skillname` in Claude Chat/Code

## Skill Structure

```markdown
# SkillName

**Purpose:** Clear one-liner

**When to use:** Specific context

## Instructions

[Step-by-step guide]

## Input Format

[What to provide]

## Output Format

[What you'll get]

## Examples

[1-2 concrete examples]

## Next Steps

[What comes after]
```

## What Makes a Good Skill

- ✅ Clear, specific purpose
- ✅ Reusable across contexts
- ✅ Works across Claude Chat, Cowork, Code
- ✅ Has clear inputs/outputs
- ✅ Includes examples
- ✅ Fast to run

## Output

Your new skill, ready to use as `/yourskillname` anywhere in Claude
