# Table Prompter

**Purpose:** Create structured, table-based prompts for consistent, publishable output

**When to use:** You need organized, structured data that could go in a table, spreadsheet, or database

## Instructions

1. **Define your goal** - What structured data do you need?
2. **Identify columns** - What information goes in each column?
3. **Specify format** - Table, CSV, JSON, or Markdown?
4. **Set constraints** - How many rows? Any required fields?
5. **I'll create** - A prompt that reliably outputs structured data

## Template

```
| Column 1 | Column 2 | Column 3 |
|----------|----------|----------|
| Value    | Value    | Value    |
```

## What This Solves

- Turning freeform output into organized data
- Creating consistent, comparable entries
- Making output suitable for databases
- Enabling sorting, filtering, analysis
- Publishing-ready formatted content

## Output Specifications

Your prompt will include:
- Clear column definitions
- Required vs. optional fields
- Format requirements
- Example rows showing expected output
- Validation rules
