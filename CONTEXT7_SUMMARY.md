## 📊 Context7 MCP Overview

### Two Available Tools

#### 1. **resolve-library-id**
Finds and resolves any library/framework to its Context7 ID
```
Input: "React" + "hooks"
Output: /facebook/react (with versions, reputation, coverage)
```

#### 2. **query-docs**
Gets current documentation and code examples
```
Input: /facebook/react + "useState hook"
Output: Official React docs with working examples
```
